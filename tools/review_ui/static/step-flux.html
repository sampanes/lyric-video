Step 6 — Flux Candidates

What This Step Does
Drop one prompt per candidate into inputs/prompts/ (filename becomes the candidate label). The batcher queues a Flux text-to-image run per file at 832x480 with a seed derived from the filename so re-runs reproduce. An anti-text suffix is appended automatically so Flux doesn't paint fake signs and watermarks on your scene.
What This Will Run
python scripts\queue_flux_candidates.py "your-slug"
