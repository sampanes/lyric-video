Step 1 — Intake

What This Step Does
Create a new song folder with the canonical subdirectory layout. Capture metadata (title, artist, song vibes, optional BPM). Locate the audio file and the lyric file you've dropped into the folder. Result: a song.json wired to its inputs, ready for Step 2.
What This Will Run
python scripts\intake_song.py "your-slug"
