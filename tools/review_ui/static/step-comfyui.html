Step 5 — ComfyUI

What This Step Does
Bring up the local ComfyUI API server so Steps 6 and 7 can queue Flux and Wan jobs to it. The server reads its install path from LOCAL_CONFIG.json's comfyui block. Treat ComfyUI as a local API, not a UI to click — Step 6 and Step 7 do all the clicking for you.
What This Will Run
python scripts\comfyui_server.py status
python scripts\comfyui_server.py start
python scripts\comfyui_server.py stop

Coming soon. Milestone 5 will put a status indicator (green dot = running, red = down) here with Start / Stop buttons.

For now, run python scripts\comfyui_server.py status in your terminal and follow up with start if it's not running.
